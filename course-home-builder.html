The footer already carries the school name, your course name, and the copyright line. Add one more line here if you want — a support email, an office-hours reminder, a class motto.

Putting it in Canvas

  1. Click Copy HTML in the panel to the right.
  2. In Canvas, go to Pages › + Page and title it Course Home (or edit your existing home page).
  3. In the editor toolbar, switch to HTML view — the </> button on the right end.
  4. Select everything already in the box, delete it, then paste. Click Save.
  5. From Pages, open the page's … menu and choose Use as Front Page.
  6. Go to Home › Choose Home Page and pick Pages Front Page.

Every style is written inline because Canvas strips <style> blocks. Editing the page in Canvas's rich-text view can scramble that formatting — come back here to make changes, then re-paste.
